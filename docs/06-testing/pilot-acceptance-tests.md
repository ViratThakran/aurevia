# Pilot Acceptance Tests

## Voice
- [ ] Speech reaches STT.
- [ ] AI responds.
- [ ] TTS streams.
- [ ] Latency meets defined target.
- [ ] Interruption stops/cancels speech.
- [ ] New turn is understood.
- [ ] Connection failure is handled.

## Sales
- [ ] Identify intent.
- [ ] Qualify.
- [ ] Explain approved information.
- [ ] Handle objection.
- [ ] Never invent product information.
- [ ] Schedule follow-up.
- [ ] Book meeting.
- [ ] Escalate to human.
- [ ] Record outcome.

## Memory
- [ ] Store useful fact.
- [ ] Retrieve later.
- [ ] Use naturally.
- [ ] Correct stale fact.
- [ ] Prevent cross-tenant access.

## Security
- [ ] Tenant A cannot access Tenant B.
- [ ] Unauthorized tool call rejected.
- [ ] Provider secrets inaccessible to clients.
- [ ] Webhook authentication works.

## Compliance
- [ ] Disallowed call blocked.
- [ ] Outside-window call blocked.
- [ ] Required consent/policy state verified.
- [ ] Decision audited.

A pilot is not accepted from one successful demo; critical tests and regression scenarios must pass.
